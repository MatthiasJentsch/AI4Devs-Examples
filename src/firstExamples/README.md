# first examples

## Installation

```bash
npm install @langchain/core @langchain/langgraph @langchain/openai @langchain/community @langchain/tavily dotenv
```
## Run the examples

To run the first example, make sure to fill in the `.env` file with your OpenAI API key and then execute the following command from the root of the project where the `.env` file is located:

```bash
npx tsx src/firstExamples/1_agent_simple.mts

# or

npx tsx src/firstExamples/2_agent_workflow.mts
```
